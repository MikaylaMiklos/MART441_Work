<H1>Reflection</H1>
<H2> Conceptual Understanding </H2>
What was the most important thing you learned about working in 3D space with Three.js? How is this different from working in 2D (Canvas or Phaser)?

I think the most important and challenging thing I learned about working in a 3D space was placement. This is very different than working in 2D because I felt like I had much more control over the positioning of objects. I've had similar experiences working between Blender and 2D drawing, taking into account multiple perspectives of viewing an image is hard for me to conceptualize. Conveying form is not usually the hard part, its having to account for a point of view that's not static.

<h2>Technical Challenges</H2>
What was the most challenging part of this project (camera positioning, lighting, model loading, scale, rotation, debugging)? How did you work through it? Did you use Gen AI? How and why?

I had challenges with scaling, object positioning, and rotation. I think I was working on a very small scale because I exported and loaded in my 3D model first and was working around its size rather than scaling it up. This made it difficult working with my shapes because they are pretty small in turn, while I also had to think about the 3D space as well for their scale. Positioning the objects was a little confusing because I am not used to thinking about where I want to put my objects in 3D space, when I work in blender I can visually see where I want to put them and manually place the objects where I want. Working in code is much more tedious because I have place the object by coding it's origin, which was disorienting for me. Lastly I used Gen AI to resolve an issue I was having with rotating an object, it was a problem with the functions i was calling and using Copilot cleared up the confusion.


<h2>Design & Intent</h2>
Describe the intention behind your scene. What were you trying to create visually or experientially? How did your use of shapes, motion, and models support that goal?

The intention behind my scene was predominantly experimentation with some visual direction. First thing I wanted to test was to see if I could export an object from blender I made and use it in this project. Which it did work! However, my visual direction took a different path than the intention behind my 3D model. I wanted to visually create a scene that took inspiration from the Frutiger Aero aesthetic with the 3D model being the focus. Frutiger Aero relies heavily on the colors bright blue, greens, and whites. I intended the shapes included in my scene to mimic the bubbles and clouds commonly featured in the aesthetic as well. The line is meant to represent the ground and greens, I think I could have pushed this more with a plane however.


<H2>Growth & Iteration</H2>
If you had more time, what would you improve or add next? What part of Three.js are you most interested in exploring further? 

I think if I had more time I'd really like to push this scene and try and create a more dynamic background. I envision it looking more like a stage and having objects/shapes for the 3D model in the center. I would also probably swap my 3D model out for something else more in the same direction as the aesthetic, I was just really excited to use my model in this project. I am mostly interested in creating artistic pieces with three.js I think it could be really fun for me.
